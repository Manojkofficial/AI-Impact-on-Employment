1. # AI-Impact-on-Employment
Machine learning project to analyze AI adoption and predict layoff risk using Python, MongoDB, Logistic Regression, and Random Forest, with data visualization, CRUD operations, and model evaluation.


AI Impact on Employment: Layoff Risk Prediction using Machine Learning and MongoDB.

2. Dataset Description
Dataset title: AI Impact on Jobs and Layoff Risk Dataset.
Source: Kaggle.
Dataset link: https://www.kaggle.com/datasets/shivasingh4945/ai-impact-on-jobs-and-layoff-risk-dataset/data
The dataset contains 20,000 records and 16 columns. The fields include Age, Education_Level, Years_of_Experience, Industry, Job_Role, Company_Size, Job_Level, Routine_Task_Percentage, Creativity_Requirement, Human_Interaction_Level, AI_Adoption_Level, Number_of_AI_Tools_Used, AI_Usage_Hours_Per_Week, Tasks_Automated_Percentage, AI_Training_Hours, and Layoff_Risk. Layoff_Risk is the target variable with High, Medium, and Low categories.
The target distribution is High: 6,797 records; Low: 6,602 records; Medium: 6,601 records. The dataset has no missing values or duplicate rows according to the initial checks.


3. This project analyzes employment data to explore layoff-risk patterns associated with employee characteristics, industries, and AI adoption. It uses Python, Pandas, MongoDB, and PyMongo for data processing and database operations, and implements Logistic Regression and Random Forest to classify layoff risk. The project includes data visualization, CRUD operations, model evaluation, and performance comparison.

4. **Technologies:** Python, Pandas, Scikit-learn, MongoDB, PyMongo, Matplotlib, Seaborn, Jupyter Notebook.
