# AI-Impact-on-Employment
Machine learning project to analyze AI adoption and predict layoff risk using Python, MongoDB, Logistic Regression, and Random Forest, with data visualization, CRUD operations, and model evaluation.


AI Impact on Employment: Layoff Risk Prediction using Machine Learning and MongoDB.

This project analyzes employment data to explore layoff-risk patterns associated with employee characteristics, industries, and AI adoption. It uses Python, Pandas, MongoDB, and PyMongo for data processing and database operations, and implements Logistic Regression and Random Forest to classify layoff risk. The project includes data visualization, CRUD operations, model evaluation, and performance comparison.

**Technologies:** Python, Pandas, Scikit-learn, MongoDB, PyMongo, Matplotlib, Seaborn, Jupyter Notebook.
